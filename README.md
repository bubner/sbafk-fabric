# sbafk-forge
### Continued port of [sbafk](https://github.com/bubner/sbafk) for Fabric 1.21.10
This custom module was created to allow an easier AFK experience on Hypixel SkyBlock with Discord webhook notifications on disconnect, server kicking, and chat scanning for specific lobby kicking events.
Offers an invasive or non-invasive mode, whether to try and take action or to simply alert the Discord webhook.
<br><br>
Command: `/sbafk`
